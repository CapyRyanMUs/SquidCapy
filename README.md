<h1 align="center">Capy na Batatinha</h1>

<p align="center">Batatinha frita, 1, 2, 3… com capivaras!</p>

Um jogo 2D inspirado em Round 6: corra até a chegada, pare quando a boneca
olhar e cuidado com os empurrões e tropeços. Jogue **offline com NPCs** ou
com amigos no **multiplayer por IP para até 8 jogadores**.

## Baixar e jogar

| Plataforma | Download | Como jogar |
| --- | --- | --- |
| Windows x64 | **[Baixar para Windows](https://github.com/CapyRyanMUs/SquidCapy/releases/download/multiplayer-preview-1/CapyMultiplayerWindows.zip)** | Extraia o ZIP e abra `CapyMultiplayer.exe`. Mantenha os arquivos juntos. |
| Android arm64 | **[Baixar APK](https://github.com/CapyRyanMUs/SquidCapy/releases/download/multiplayer-preview-1/CapyMultiplayerAndroid.apk)** | Instale o APK; autorize a instalação pela fonte utilizada, se solicitado. |

**Prévia de testes:** os pacotes são builds de depuração. A validação em Android
real ainda está pendente. Não é necessário instalar a Godot.

## O básico

- **Offline:** abra o jogo e escolha Offline.
- **Com amigos:** um jogador hospeda e os demais entram pelo IP dele, usando
  a mesma porta (padrão 7000/UDP). Todos marcam pronto e o anfitrião inicia.
- **Windows:** setas para mover, Shift para correr, Espaço para empurrar e
  Ctrl repetidamente para levantar. No Android, use os controles de toque.

Pela internet, a conexão depende de o anfitrião estar acessível; CGNAT pode
exigir uma rede virtual externa. O GitHub hospeda os downloads, não as partidas.
